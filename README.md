# Dustline Arena — 3D Top-Down Shooter

Одиночный 3D-шутер с видом сверху. Пройдите пять арен и переживите волны зомби, подбирая оружие, патроны и аптечки.

## Что уже сделано

- Пять арен с переходами между ними, растущей сложностью и итогами операции.
- Пистолет, ПП, дробовик, автомат, гранаты и уклонение. Убийства дают шанс на боеприпасы и лечение.
- Четыре варианта зомби, волны противников и навигация на базе NavMesh. Пулы переиспользуют врагов и снаряды.
- Главное меню, боевой HUD, пауза, повтор арены после поражения, музыка и настройки громкости.

## 🛠 Технологии

`Unity 2022.3 LTS` · `C#` · `URP` · `NavMesh` · `Git LFS`

## Управление

| Действие | Клавиши |
| --- | --- |
| Движение | WASD или стрелки |
| Прицеливание и огонь | Мышь и левая кнопка |
| Перезарядка | R |
| Граната | Удерживайте и отпустите G или правую кнопку мыши |
| Уклонение | Пробел или левый Shift |
| Пауза | Esc |

## Сборка и проверка

Откройте проект в Unity 2022.3.62f2 с модулем Windows Build Support. В меню `Dustline Arena → Run Arena Smoke Tests` проверьте навигацию, точки появления врагов и коллайдеры всех пяти арен. Тесты здоровья и боеприпасов доступны в Unity Test Runner на вкладке Edit Mode.

Команда `Dustline Arena → Build Windows x64 Release` создаёт `Builds/Windows-x64/DustlineArena.exe`. Для запуска на другом ПК перенесите всю папку `Windows-x64`.

Перед публикацией проверьте в собранной игре переходы между аренами, паузу, повтор после поражения и итоговый экран. Пройдите кампанию без отладочных команд, чтобы оценить сложность и запас боеприпасов. Добавьте в архив [титры](CREDITS.txt).
