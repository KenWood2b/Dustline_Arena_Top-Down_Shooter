# Dustline Arena — 3D Top-Down Shooter

Игровой прототип динамичного top-down shooter, разработанный на Unity.

## 🚀 О проекте

- Реализованы передвижение, прицеливание, стрельба и несколько типов оружия.
- Добавлены волны противников с навигацией на базе NavMesh.
- Настроены точки появления, подбор оружия и награды за уничтожение врагов.
- Добавлены анимации игрока и противников, камера и базовый игровой интерфейс.
- Реализованы пулы противников и снарядов для снижения нагрузки во время боя.
- Добавлен стресс-тест производительности до 500 противников в Unity Editor.

## 🛠 Технологии

`Unity 2022.3 LTS` · `C#` · `URP` · `NavMesh` · `Git LFS`

## 📌 Статус

Проект находится в активной разработке. Сейчас выполняются профилирование, оптимизация систем боя и тестирование больших волн противников.

## 📋 В планах

- Новые типы противников и более разнообразные волны.
- Улучшенный HUD и экраны состояния игры.
- Звуки, эффекты попаданий и дополнительная обратная связь оружия.
- Баланс сложности и подготовка Development Build.
